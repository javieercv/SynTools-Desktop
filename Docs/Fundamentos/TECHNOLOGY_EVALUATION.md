# Evaluación tecnológica

> No existe todavía una tecnología aprobada.

## Candidatos iniciales

- .NET + Avalonia.
- C++ + Qt.
- Ruta multiplataforma que conserve una parte mayor de Swift, si demuestra ser sostenible para UI y servicios requeridos.

Pueden estudiarse otros candidatos si aportan una ventaja material.

## Prueba técnica obligatoria

La comparación no será un Hello World.

Cada candidato debe demostrar como mínimo:

- una UI compartida;
- navegación estilo SynTools;
- tema claro/oscuro;
- selector de archivo y carpeta;
- drag & drop;
- SQLite;
- Ajustes simples;
- un coordinador de operación;
- lanzamiento de FFmpeg con argumentos separados;
- stdout/stderr;
- progreso;
- cancelación del proceso y descendientes;
- gráfica/render personalizado;
- portapapeles;
- abrir ruta/URL;
- reproducción multimedia básica o una prueba equivalente suficiente para evaluar el Inspector;
- build y empaquetado real en macOS;
- build y empaquetado real en Windows.

## Criterios de comparación

Se documentarán al menos:

- porcentaje real de código compartido;
- calidad de UI de escritorio;
- accesibilidad;
- rendimiento;
- consumo de memoria;
- arranque;
- render/gráficos;
- integración con motores;
- procesos/cancelación;
- multimedia;
- packaging y firma;
- tamaño del producto;
- madurez;
- mantenimiento;
- ecosistema;
- facilidad de pruebas;
- soporte macOS Apple Silicon;
- soporte Windows x64;
- camino a Windows ARM64;
- dependencia de componentes web;
- coste de complejidad.

## Decisión

No se elegirá una tecnología solo por preferencia del desarrollador.

El usuario aprobará la elección después de revisar los resultados de la prueba.
