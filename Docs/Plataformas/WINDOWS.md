# Plataforma Windows

## Objetivo inicial

- Windows 11.
- x64.

## Futuro

La arquitectura debe evitar decisiones que bloqueen innecesariamente Windows ARM64.

## Principio

Windows debe recibir el mismo producto común, no un subconjunto arbitrario.

Una diferencia funcional solo se acepta cuando:

- la capacidad depende realmente del sistema;
- no existe una alternativa razonable;
- está documentada;
- está aprobada;
- la UI la comunica honestamente.

## Áreas a investigar

- procesos y árboles de procesos;
- almacenamiento seguro de credenciales;
- instalación y actualización manual/controlada;
- firma;
- rutas de datos;
- Papelera;
- APIs multimedia/aceleración;
- integración con Explorer;
- permisos;
- empaquetado de motores.
